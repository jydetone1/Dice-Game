# Dice Game App

This is a simple interactive Dice game built with **Next.js**, **TypeScript**, **Zustand**, and **Material UI (MUI)**. The game lets the user guess whether a random number will be over or under their chosen number.

## Tech Stack

- **Next.js App Router**
- **React 18**
- **TypeScript**
- **Zustand** – for state management
- **MUI (Material UI)** – UI library
- **Styled Components / @mui/system** – for custom styling

## Getting Started

```bash
npm install
npm run dev
```
